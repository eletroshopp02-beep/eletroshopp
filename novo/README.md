# Eletroshopp — Novo projeto

Nova arquitetura da loja, isolada da versão atual.

## Objetivos
- catálogo com fonte única de dados;
- busca e categorias;
- página de produto;
- carrinho persistente;
- checkout estruturado;
- CEP/endereço;
- cálculo de frete sem valor fixo;
- registro do pedido;
- encaminhamento para WhatsApp;
- PWA instalável;
- interface mobile-first;
- separação clara entre loja, dados e serviços.

A branch `eletroshopp-novo` é o ambiente de desenvolvimento. A branch `main` permanece preservada durante a reconstrução.
